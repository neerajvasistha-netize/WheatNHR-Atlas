# Ponce-Molina et al. (2026) FHB GWAS: supplementary tables (seed_ad85)

Supplement (pdis-03-25-0577-re.sm.pdf) supplied by the owner on 24 Nov 2026; the PDF is not kept here.
`build85.py` reads Supplementary Table S10 (all QTN, 40K and 90K arrays) and takes PVE from Tables S7 and S9.
Kept: 76 QTN for FHB traits (incidence, severity, FHB index, FDK, DON) with a physical position.
Left out: QTN for heading date or plant height only, and 5 QTN with unknown position.
Positions are RefSeq v1.0 (the supplement names no assembly, but the 90K positions match published v1.0 coordinates).
Records PM6-001 onward, grade A, class QTN; pangenome positions added as for seed_ad84.
`added_records.tsv` lists them.
