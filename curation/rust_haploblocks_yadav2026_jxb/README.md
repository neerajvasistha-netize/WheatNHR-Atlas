# Yadav S et al. (2026) rust haploblocks: Supplementary Tables S4 and S5 (seed_ad90)

Supplementary workbook (erag073_Supplementary_Tables_-_updated.xlsx) supplied by the owner on 24 Nov 2026; not kept here.
`build90.py` adds every haploblock in Table S4 (52 consistent stripe rust blocks) and Table S5 (50 top leaf rust blocks)
of the OzWheat panel as interval records (grade B) on IWGSC RefSeq v1.0, with the authors' overlap notes.
Blocks that appear in both tables are entered once per disease. Records YH6-001 onward. `added_records.tsv` lists them.
